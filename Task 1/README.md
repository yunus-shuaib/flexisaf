# ES6 JavaScript Fundamentals

## Overview
This project demonstrates key ES6 features in JavaScript including variables, scope, functions, arrays and array functions (like map, filter and reduce), objects and import.

## let and const

let is used in block scoped and can be reassigned.

const is used for variable that cannot be reassigned:
```js
const data = [];
```

## Scope
- Global scope: accessible everywhere
- Block scope: accessible only inside {}

## Closure
- All function can update or access data through closure. Even when called as imported function in another .js file.

## Summary
Covers ES6 fundamentals: let, const, scope, arrow functions, arrays, and objects.
